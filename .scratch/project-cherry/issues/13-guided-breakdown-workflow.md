# Guided manual breakdown workflow

Type: prototype
Status: open
Blocked by: 06, 07

## Question

How should the no-AI breakdown workflow behave and feel? Prototype the guided flow that takes a daunting task to a set of startable steps: the question sequence, how steps are captured and bucketed, when the flow stops the user from over-planning, how a too-big step is promoted to its own task, and how breakdown is offered (at capture, on demand, or when a task sits unstarted).
